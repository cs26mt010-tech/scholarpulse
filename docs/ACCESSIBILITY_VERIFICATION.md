# ScholarPulse Accessibility Verification Record

Status: **Not yet signed off**. This file is a verification record, not a claim that WCAG
conformance has already been achieved.

## Required manual checks

| Check | How to verify | Status |
|---|---|---|
| Keyboard-only navigation | Tab/Shift+Tab through navigation, search, filters, cards and dialogs; Enter/Space activate controls | Pending |
| Visible focus | Confirm every interactive element has a clearly visible focus indicator | Pending |
| Contrast | Measure text, controls, borders and focus indicators against WCAG 2.2 AA applicable contrast ratios | Pending |
| Labels | Confirm every input has an accessible name; placeholder alone is insufficient | Pending |
| Semantic structure | Verify landmarks, heading order, button/link semantics and list/table semantics | Pending |
| Screen reader | Test key browse/search/resource-view flow with a screen reader | Pending |
| Zoom/reflow | Test at 200% zoom and narrow viewport without loss of content or functionality | Pending |
| Motion | Check reduced-motion preferences and avoid essential information conveyed only by animation | Pending |
