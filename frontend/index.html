4. Graph Traversal & Shortest Paths

Breadth-first search (BFS)

BFS explores vertices in increasing distance from the source. It uses a queue and visits each vertex at most once.

Time complexity: O(V + E)
Key idea & Full Excerpt

When all edges have equal weight, BFS returns shortest paths by number of edges.
